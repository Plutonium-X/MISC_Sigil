# Mod d'anniversaire du Forum Sigil.cz

Ce mod a été crée par l'équipe de Sigil.cz pour célébrer l'anniversaire du forum.  
Vous gagnez automatiquement au début de chaque partie ou après rechargement une amulette qui vous permet de convoquer "à volonté" l'une des 12 célèbres personnalités du forum. 

Chaque personnalité vous aidera, soit si vous êtes hors combat en lançant sur le joueur un sort de buff (Hâte améliorée, Invisibilité majeure)... ou en vous donnant un parchemin, soit si vous êtes en combat en lançant un sort offensif sur l'ennemi (Arrêt du temps, Sort d'assaut...).  

Le code est écrit de telle sorte que si la personnalité lance un sort de buff vous pourrez la réinvoquer, mais si elle lance un sort offensif vous ne pourrez plus.

La méthode est contraignante (vous devez "examiner" une amulette portée), mais ça vaut le coup.  
  
  
Notes :  
Ce mod s'installe aussi sous IWDEE.  
Il existe <a href=https://github.com/Deratiseur/Mods_Tweaker>un mod</a> pour rendre les deux options infinies et l"utilisation de l'amulette moins contraignante.

# Sigil.cz Forum Anniversary Mod

This mod was created by the Sigil.cz team to celebrate the forum's anniversary.

At the start of each game, or after reloading a saved game, you automatically receive an amulet that allows you to summon one of 12 well-known forum personalities "at will".

Each personality will help you in one of two ways: if you are out of combat, they will either cast a buff spell on your character (Improved Haste, Improved Invisibility, etc.) or give you a scroll. If you are in combat, they will cast an offensive spell at an enemy (Time Stop, Spellstrike, etc.).

The code is designed so that if the summoned personality casts a buff spell, you can summon them again. However, if they cast an offensive spell, you can no longer summon them.

The method is rather cumbersome (you have to "examine" an equipped amulet), but it's worth it.

**Notes:**
- This mod can also be installed on IWDEE.
- There is <a href="https://github.com/Deratiseur/Mods_Tweaker">a mod</a> that makes both options unlimited and the amulet much easier to use.
